# 当前能力与后续候选

## 已实现

A 手动发布，B 按需安装/更新/同步；中文网页，项目分类，版本、回滚、设备心跳和公开发现；目录/ZIP、50 MiB 默认总量、流式校验、上传恢复与清理；本地修改/未知同名目录保护、备份和失败恢复。

网页默认初始密码与服务端强制改密（不再要求改密所有权证明）、单管理员账号密码、scrypt、安全 Cookie、CSRF、D1 限速、改密码、退出及可信 D1 恢复；publisher/client 项目 Token、定期或永久有效、撤销；AI 初始化脚本及独立凭据文件；测试隔离 Agent 配置。

## 后续候选（尚未实现）

MFA / Passkey、独立凭据保险库、更多 AI 客户端及发现路径矩阵、跨配置目标锁、备份保留策略与配额管理、分片直传和字节级续传、内容审核与签名。自动双向同步不是当前用户流程的要求，不为了这个目标改动 publish → update 的手动用法。

实际 Cloudflare 套餐压力、WAF、生产灾备和真实模型加载需要单独验收。不能将本地/CI 测试替代线上验收。

当前个人自用暂不推进性能扩展或容量治理；按实际使用再评估，不因泛化场景提前增加复杂度。
