# 当前范围与后续候选

## 已明确的主要使用方式

**A 修改 Skill 后手动发布，B 需要时手动更新。** `publish → install / update` 已有实现；订阅后手动 `sync` 用于同时接收新增技能。自动监控、自动回传和多端自动合并不是完成这一目标的前提，也不是当前开发承诺。

## 当前代码包含

- 私人项目、管理员/只读客户端令牌、技能版本、回滚、设备上报及公开发现。
- 网页与 CLI 目录 / ZIP 发布，可配置大小/数量限制、流式校验和私有 R2 存储。
- 上传进度、取消、完整包会话恢复、幂等发布、上传期间的版本冲突检查和有界清理。
- 三种客户端目录适配、手动安装/更新、本地修改保护、备份和失败恢复。
- 未变化的同步不重复下载；下载前严格检查 manifest；恢复上传核对私有/公开选择。
- 本地和 CI 测试。具体已验证范围见 [测试报告](TEST_RESULTS.md)。

## 首次使用前待验收

当前尚未在实际使用环境安装部署。先按 [首次部署](SETUP.md) 完成一个 Hub 的资源和网页初始化，再验证 A 发布、B 安装、A 再发布、B 手动更新，以及所用 Hermes / Claude Code 的真实加载。

同时核对实际 Agent 路径、项目令牌范围、私有文件访问、真实 Cloudflare 套餐配额和备份。不要把测试目录中的文件复制成功视为所有 AI 工具已完成执行验收。

## 后续候选（未实现）

- 限定项目的发布角色、独立凭据保护和更方便的实例配置。
- 更多 AI 工具适配、实际扫描目录检查和项目级安装。
- 本地修改对比、已有技能接管的显式流程、批量导入。
- 存储/流量配额、历史包与备份保留策略、灾备恢复演练。
- 字节级断点续传、R2 预签名直传及更大包的校验队列。
- Windows 原生凭据存储、跨配置目标锁、遗留锁恢复。

这些条目不是当前已具备的功能，也不会默认为用户开启自动同步、自动发布或自动部署。
