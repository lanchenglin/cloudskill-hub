## 覆盖重点

保留原有 40 项上传/下载/安装回归，并增加密码随机盐、Unicode/长度限制、默认密码仅限初始化、无自动全站 API Token、会话 Cookie 属性、CSRF、来源校验、错误统一、过期/退出、密码变更、重新验证、Token 到期/撤销、项目越权、公开权限拒绝、旧数据转换、初始化及可信恢复测试。

原有边界仍包括模拟 D1/R2 下的 50 MiB + 1000 文件、ZIP/路径攻击、校验错误、并发版本冲突、恢复/清理和本地修改保护。真实本地 Worker 的大包测试是 7 MiB，不冒充线上满额压力测试。

本地 Snap Chromium 的 /tmp 隔离影响了测试文件路径，测试支持显式 BROWSER_TEMP_DIR 和下载目录，并直接传送 ZIP 字节；上传和独立 Python ZIP/CRC 下载断言均保留并通过。GitHub 使用独立 Playwright Chromium。

## 首次登录新增覆盖

11 项首次登录测试覆盖初始密码的精确例外、22 类受保护操作的服务端门禁、CSRF/会话/当前密码校验、无 Secret 首次改密、刷新/多次登录/退出/旧会话失效、自定义初始密码仍需更换、旧管理员与读取 Token 不能绕过、可信强密码恢复、004 迁移不修改已有密码及会话。

本次额外覆盖：旧待改密账号即使仍保存 activation_secret_hash，也不要求提供证明；旧请求附带已废弃的 bootstrapSecret 不影响改密；首次创建账号仍必须持有部署授权。浏览器验证额外输入框已移除，并检查改密请求只发送 currentPassword/newPassword。相应回归用例在修改前复现失败，再在修改后验证通过。

## 永久 Token 新增覆盖

本次新增 10 项回归：7 项接口/期限策略/参数解析测试，以及 3 项 AI 初始化脚本测试。验证显式 null 为永久、省略为90天、1–365边界、无效类型不签发、永久仍受角色与项目限制、单个及全部撤销、定期仍会到期、首次改密/CSRF/重新验证不能绕过、网页登录期限不变。接口回归在修改前复现了 null 被错误回退为90天，修改后通过。

初始化脚本覆盖永久 A/B、新参数不修改已有永久/定期令牌、报告服务器实际期限、无效参数在网络与凭据写入前拒绝、日志不回显 Token。Chromium 覆盖默认90天、选择永久/30天、请求中的 null/整数、永久列表刷新及撤销不影响另一令牌；原生本地 Worker 使用永久 publisher/client 完成7 MiB上传与三端文件安装，并验证单独撤销与定期签发。

本次没有新增迁移或改写已有 Token，没有改默认登录/强制改密、会话时限、上传限制、权限、性能设计、Cloudflare 绑定和自动部署开关。新增永久选项不等于所有真实 AI 运行环境均已验收。
